# uTube 2.5.0

Save public videos from **YouTube, X, Instagram, and Facebook** on desktop, Android, or the command line.

## What changed

- Download public X/Twitter videos, Instagram Reels and video posts, and Facebook videos and Reels as MP4 or MP3.
- Select individual videos in X posts and Instagram video carousels. Facebook share links and `fb.watch` links resolve to the original video.
- Choose the available quality. Facebook keeps SD/HD labels when exact dimensions are unavailable; failed HD downloads can fall back to SD.
- Android accepts links shared from supported apps, prepares fresh media links in the background, and keeps thumbnails in download history.
- Keep metadata and media requests restricted to each provider's hosts, with cancellation, bounded responses, and clear unavailable-video messages.
- Use shorter English/Arabic download headings and keep desktop download percentages beside their status text.
- Fix Intel macOS artifact collection when building from Apple Silicon.

## Downloads

**CLI:** `npm install -g utube-cli@2.5.0` (Node.js 20+).

**Linux x64:** DEB, AppImage, and ZIP. Use `sudo apt install ./uTube-Desktop-2.5.0-linux-x64.deb` for Debian/Ubuntu.

**Android 10+:** the universal APK supports ARM64 and x86-64. Smaller architecture-specific APKs are included. All use the existing permanent production key, version 2.5.0 and version code 5, so they can update an official release while keeping app data.

Checksums accompany the files. Android also includes its signing certificate, verification report, third-party notices, and matching media-library sources.

## Supported links

YouTube videos and playlists remain supported. The added providers support public videos accessible without signing in. Private/login-restricted content, Stories, photos, live streams, and streams without a supported downloadable MP4 are not supported. Availability can change when a provider updates its site or limits anonymous requests.

Desktop and CLI need FFmpeg for MP3 conversion and separate video/audio merging; download it from the app when offered. Native combined MP4 streams from X, Instagram, and Facebook can download without it. Android includes its media tools.
