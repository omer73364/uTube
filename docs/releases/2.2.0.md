# uTube 2.2.0

Build your offline collection with the new desktop app, or keep downloading from your terminal.

## Desktop

- Preview videos and playlists, choose individual items, and download MP4 videos or MP3 audio.
- Keep your queue and history across restarts, search by video or playlist, and open completed files directly.
- Choose light, dark, or system appearance. Use English or Arabic with full right-to-left layout support.
- Cancel downloads, retry interrupted items, and keep your folder and preferences between sessions.

## Better downloads in both interfaces

- Try alternate encodings and clients at your requested quality before falling back to the best working lower resolution.
- Retry rejected stream ranges quietly, with progress that does not keep restarting.
- Share one download engine between the terminal and desktop.

## Downloads

- **Linux x64:** `.deb`, `.AppImage`, or `.zip`.
- **Windows x64:** `Setup.exe` or `.zip`.
- **macOS:** `.dmg` or `.zip`, separately labeled for Apple Silicon (`arm64`) and Intel (`x64`).
- **CLI:** `npm install -g utube-cli@2.2.0` once the npm version is available.

Install the Debian package with `sudo apt install ./uTube-Desktop-2.2.0-linux-x64.deb`; apt installs FFmpeg as a dependency. For AppImage, make the file executable before opening it. ZIP archives must be extracted completely before launching the app.

**FFmpeg is required separately for MP3 conversion and HD merging on Windows, macOS, and portable Linux builds.** These desktop builds are unsigned and macOS builds are not notarized, so operating-system security prompts may appear. Use the SHA256SUMS files to verify downloads.

This is the first public desktop preview. Linux has desktop integration coverage; native Windows and macOS packages are built on their own runners, but interactive testing on those platforms is still limited. Interrupted downloads restart from the beginning when retried. Automatic desktop updates are not included.
