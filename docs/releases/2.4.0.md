# uTube 2.4.0

FFmpeg setup is now built into the desktop and CLI, and Android joins the same version number.

## What changed

- Download FFmpeg when uTube needs it, with progress, cancellation, retry, and verified downloads saved for uTube only. No administrator access or system-wide installation is needed.
- Desktop startup offers setup when FFmpeg is missing. Status messages take you directly to its Settings section; successful setup returns Home.
- The CLI offers setup at startup and through `utube --install-ffmpeg`, with Yes selected by default in interactive sessions. Scripted commands never download it without an explicit request.
- About screens show the app version, GitHub project, and open-source licenses in English and Arabic.
- Clearer instructions and errors, a unified uTube app name, refreshed website fonts, and real phone screenshots in both languages.

## Downloads

**CLI:** `npm install -g utube-cli@2.4.0` (Node.js 20+).

**Linux x64:** DEB, AppImage, and ZIP. Install the DEB with `sudo apt install ./uTube-Desktop-2.4.0-linux-x64.deb`. AppImage and ZIP users can download FFmpeg from Settings.

**Android 10+:** `uTube-android-2.4.0.apk` includes both supported CPU types. Smaller `arm64-v8a` and `x86_64` APKs are also provided. All are signed with the existing permanent release key; install over the previous release to keep app data. The download includes its JavaScript and media tools, so no additional setup is needed.

**Windows/macOS:** 2.4.0 unsigned previews are available: Windows x64 EXE/ZIP, plus macOS Apple Silicon and Intel DMG/ZIP. Unsigned Windows builds can trigger SmartScreen; macOS previews are not notarized and can trigger Gatekeeper warnings. They are not equivalent to trusted signed releases.

Checksums accompany the downloads. Android also includes its signing certificate, verification report, third-party notices, and matching media-library source archive.

The optional desktop/CLI FFmpeg download uses pinned third-party `ffmpeg-static` assets, not bundled executables. The upstream label `b6.1.1` includes different versions by platform (Linux x64 reports 7.0.2); system FFmpeg is preferred when available. See [setup details](../ffmpeg-setup.md).
