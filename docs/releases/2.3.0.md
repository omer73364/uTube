# uTube 2.3.0

A shared red identity, a clearer desktop library, and smoother terminal downloads.

## Desktop and terminal

- Use Home, Library, and Downloads with thumbnail cards, playlist groups, search, and a floating navigation bar.
- Open a saved file or its folder from each video's action menu. Quality labels sit with the video details.
- Enjoy more consistent spacing, folder controls, Arabic layouts, and warm dark colors.
- In the CLI, see channel, duration, views, format, and destination together. Downloading and media processing stay in one progress display, while retries remain quiet.
- The installed desktop worker now bundles its YouTube client instead of requiring packages from the source checkout.

## Downloads

**Linux x64:** DEB, AppImage, and ZIP packages are included in this release.
Install the DEB with `sudo apt install ./uTube-Desktop-2.3.0-linux-x64.deb`;
apt also installs FFmpeg. AppImage and ZIP users need FFmpeg separately for
MP3 conversion and HD merging. Extract the entire ZIP before launching.

**CLI:** `npm install -g utube-cli@2.3.0`. Node.js 20+ and FFmpeg are required.

**Android:** the separately versioned [signed Android 1.0.0 APK](https://github.com/omer73364/uTube/releases/tag/android-v1.0.0)
is already available for Android 10+ ARM64 and x86-64 devices. It bundles its
media tools and JavaScript, and does not require Metro or a computer.

**Windows and macOS:** no new installers are published in 2.3.0. Existing 2.2.0
previews remain available and unsigned. Trusted Windows signing and macOS
notarization are required before new public installers can be released.
The signing checks have not been bypassed.

The [website](https://omer73364.github.io/uTube/) now matches the apps, with
English/Arabic copy, light/dark appearance, real screenshots you can enlarge,
and direct Android downloads.

Linux packages have SHA-256 checksums alongside the assets. Interrupted
transfers restart when retried; automatic desktop updates are not included.
