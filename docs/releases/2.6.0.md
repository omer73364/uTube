# uTube 2.6.0

Download public videos and audio from **YouTube, X, Instagram, and Facebook** on desktop, Android, or the command line.

## What changed

- Check for updates in desktop and Android Settings, view release information, and download verified installers with progress, cancellation, and retry. Installation uses the operating system's installer; portable AppImages provide a verified replacement file.
- Receive signed download-service notices without replacing the app. Affected services can pause new work while other services continue.
- Check for CLI updates automatically during interactive startup, from the menu, or with `utube --check-updates`. Update using `npm install -g utube-cli@latest`.
- See download sizes beside quality options, including Facebook and Instagram size checks when the provider does not supply the size directly. Sizes remain unavailable when a server does not expose them.
- Use simpler, themed update controls on mobile and desktop. Stop download and install appears only when a download is in progress.

## Updating

**Existing 2.5.0 users must install 2.6.0 manually once** to get the in-app updater. It uses a signed production feed hosted on the uTube website. This release then receives future compatible releases through Settings. No new version is available immediately after installing the latest release.

**CLI:** `npm install -g utube-cli@2.6.0` (Node.js 20+).

**Linux x64:** DEB, AppImage, and ZIP. For Debian/Ubuntu, use `sudo apt install ./uTube-Desktop-2.6.0-linux-x64.deb`.

**Android 10+:** signed universal, ARM64, and x86-64 APKs. Version 2.6.0 uses version code 6 and the existing production signing key, allowing upgrades from official production releases while keeping app data. PR9 test builds are separate apps and do not replace the production installation.

Checksums accompany each platform's downloads. Android includes its signing certificate, verification report, third-party notices, and matching media-library sources.

## Windows and macOS previews

Windows x64 EXE/ZIP and macOS Apple Silicon/Intel DMG/ZIP are **unsigned previews**. Windows may show SmartScreen prompts; macOS builds are not notarized and may be blocked by Gatekeeper. They are not trusted signed installers. Signed update metadata verifies the published artifact's integrity; it does not provide Windows publisher signing or Apple notarization.

## Supported content

Public, anonymously accessible videos are supported. Private/login-restricted content, Stories, photos, live streams, and streams without a supported downloadable MP4 are not supported. Provider availability and file-size information can change. Desktop and CLI need FFmpeg for MP3 conversion and separate audio/video merging; Android includes its media tools.
