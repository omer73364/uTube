# uTube logo

The rounded **u** represents uTube; the play symbol connects it to video. The
blue tile keeps the desktop app's established color. Use the same mark for
mobile, desktop, and the website, without recoloring it to match a UI theme.

The editable master is `apps/desktop/assets/icon.svg`. Desktop platform exports
are alongside it (`.png`, `.ico`, `.icns`). Mobile uses
`apps/mobile/src/ui/assets/logo.png` in its header and the matching Android
vector in `apps/mobile/android/app/src/main/res/drawable/ic_utube.xml`.
The website's existing asset-copy step consumes the master SVG.

Keep the mark square and preserve its transparent rounded corners. Do not
stretch, mirror, add a download arrow, or replace the wordmark's spelling: uTube.
