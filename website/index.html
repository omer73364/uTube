A few useful details

Before you press
download.

What happens if my chosen quality fails?

uTube tries alternate encodings and clients at your requested resolution first. If none work, it tries lower resolutions from highest to lowest and reports the quality actually saved. Available quality depends on the video.

Do I need to install anything else?

Desktop downloads include the app runtime, so you don’t need Node.js or npm. The Debian package installs FFmpeg through apt. Windows, macOS, and portable Linux downloads need FFmpeg installed separately for MP3 conversion and HD merging.

Will my downloads still be there tomorrow?

Yes. Files stay in your chosen folder, and desktop history is saved on your device. Interrupted transfers wait for you to retry; retries start from the beginning.

How do updates work?

Download a newer desktop version from GitHub Releases when you want to update. For the CLI, run the installation command again. Automatic desktop updates are not included yet.
